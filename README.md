## ✨ **Features**

<div align="center">
<table>
<tr>
<td>

### 🚀 **Core Features**
- <b>🌡️ Real-time Weather</b> via OpenWeatherMap API
- <b>🎨 Dynamic Backgrounds</b> - 6 weather-based gradients
- <b>✨ Particle System</b> - 100+ animated particles
- <b>📱 Recent Searches</b> - localStorage (max 8 cities)

</td>
<td>

### 🎨 **Visual Effects**
- <b>🥛 Glassmorphism UI</b> - Backdrop blur everywhere
- <b>⚡ Smooth Animations</b> - 60fps transitions
- <b>🏙️ Cities Carousel</b> - 10 Indian cities
- <b>📲 Fully Responsive</b> - Mobile-first design

</td>
</tr>
</table>
